# FacePoints — сканирование лица и построение 68 точек

Программа предназначена для простого сканирования лица с веб-камеры и отображения его ключевых точек.

Программа **не выполняет распознавание личности**, **не сравнивает лицо с базой данных** и **не сохраняет биометрические данные**. Она только обнаруживает лицо и строит разметку из 68 точек.

## Что делает программа

В реальном времени программа:

1. Открывает веб-камеру.
2. Находит лицо с помощью **YuNet**.
3. Переводит изображение в чёрно-белый вид.
4. Улучшает контраст изображения.
5. Передаёт найденные области лиц в **Facemark LBF**.
6. Получает 68 координат лица.
7. Рисует:
   - рамку вокруг лица;
   - 68 красных точек;
   - номера точек;
   - контуры лица, бровей, носа, глаз и рта.
8. Показывает коэффициент уверенности обнаружения лица.

Выход из программы — клавиша **ESC**.

# Используемые технологии

- C#
- .NET 8
- OpenCvSharp
- OpenCV DNN
- YuNet
- Facemark LBF
- веб-камера

OpenCvSharp — .NET-обёртка над OpenCV. Актуальный пакет `OpenCvSharp4.Windows` рассчитан на Windows и включает OpenCV с `opencv_contrib`, поэтому в нём доступны модули, необходимые для этого проекта.

## Модели

Программа автоматически загружает две модели.

### 1. YuNet

Используется для обнаружения лица.

URL:

```text
https://media.githubusercontent.com/media/opencv/opencv_zoo/main/models/face_detection_yunet/face_detection_yunet_2023mar.onnx
```

SHA-256, который проверяет программа:

```text
8f2383e4dd3cfbb4553ea8718107fc0423210dc964f9f4280604804ed2552fa4
```

### 2. LBF

Используется для построения 68 точек лица.

URL:

```text
https://raw.githubusercontent.com/kurnianggoro/GSOC2017/master/data/lbfmodel.yaml
```

Модели сохраняются в:

```text
C:\Users\Public\Documents\FacePointsModels
```

После первой загрузки программа повторно скачивает только отсутствующие или повреждённые файлы.

# Структура 68 точек

Используется стандартная схема из 68 landmark-точек:

| Диапазон | Область |
|---|---|
| 0–16 | Контур лица / челюсть |
| 17–21 | Левая бровь |
| 22–26 | Правая бровь |
| 27–35 | Нос |
| 36–41 | Левый глаз |
| 42–47 | Правый глаз |
| 48–59 | Внешний контур рта |
| 60–67 | Внутренний контур рта |

На изображении каждая точка имеет свой номер.

## Операционная система

Windows.

Рекомендуется:

```text
.NET 8
```

## Камера

Подойдёт обычная USB-веб-камера или встроенная камера ноутбука.

По умолчанию программа использует:

```csharp
new VideoCapture(0, VideoCaptureAPIs.DSHOW)
```

`0` означает первую доступную камеру.

Если камер несколько, можно попробовать:

```csharp
new VideoCapture(1, VideoCaptureAPIs.DSHOW)
```

или:

```csharp
new VideoCapture(2, VideoCaptureAPIs.DSHOW)
```

# Запуск

После запуска программа сначала проверяет модели.

В консоли появятся сообщения примерно такого вида:

```text
Проверка YuNet...
YuNet уже загружен.
lbfmodel.yaml уже загружен.
Все модели готовы.
```

После этого открывается окно:

```text
FACE 68 POINTS - ESC для выхода
```

В окне будет видеопоток с камеры.

При обнаружении лица:

- вокруг лица появляется зелёная рамка;
- точки становятся красными;
- рядом с точками отображаются их номера;
- контуры отображаются жёлтыми линиями;
- сверху показывается `68 POINTS`.

---

# Если лицо не находится

На экране появится:

```text
FACE NOT FOUND
```

Попробуй:

- посмотреть прямо в камеру;
- увеличить освещение;
- убрать сильное затемнение лица;
- приблизиться к камере;
- убедиться, что камера используется именно этим приложением.

---

# Если камера не открывается

В консоли появится:

```text
Не удалось открыть камеру.
```

Проверь:

1. Не используется ли камера другим приложением.
2. Разрешён ли доступ к камере в Windows.
3. Правильно ли выбран индекс камеры.

По умолчанию:

```csharp
VideoCapture(0, VideoCaptureAPIs.DSHOW)
```

Попробуй `1`, если первая камера занята или отсутствует.

---

# Если модель YuNet повреждена

Программа проверяет SHA-256 файла YuNet.

Если контрольная сумма не совпадает с ожидаемой:

1. старый файл удаляется;
2. модель скачивается заново;
3. SHA-256 проверяется повторно;
4. программа продолжает работу только после успешной проверки.

# Как работает программа

Общий алгоритм:

```text
Веб-камера
    ↓
Получение кадра
    ↓
YuNet
    ↓
Обнаружение лица
    ↓
Прямоугольник лица
    ↓
Facemark LBF
    ↓
68 точек
    ↓
Отрисовка точек и контуров
    ↓
Вывод на экран
```

## Этап 1 — камера

Программа получает кадры размером:

```text
1280 × 720
```

Если камера не поддерживает этот режим, фактический размер кадра может отличаться.

## Этап 2 — YuNet

YuNet определяет положение лица и возвращает данные обнаружения.

Для каждого найденного лица используются координаты:

```text
X
Y
Width
Height
```

а также значение уверенности обнаружения.

## Этап 3 — подготовка изображения

Кадр преобразуется:

```text
BGR → Grayscale
```

После этого применяется:

```text
EqualizeHist
```

для выравнивания контраста.

## Этап 4 — Facemark LBF

Для найденного лица передаётся прямоугольник:

```text
Rect(x, y, width, height)
```

Facemark LBF вычисляет 68 координат:

```text
Point2f[]
```

## Этап 5 — визуализация

Каждая точка рисуется как красный круг и получает номер.

Дополнительно строятся линии:

```text
0–16    → челюсть
17–21   → левая бровь
22–26   → правая бровь
27–35   → нос
36–41   → левый глаз
42–47   → правый глаз
48–59   → внешний рот
60–67   → внутренний рот
```

# Что программа НЕ делает

Данный проект является только модулем сканирования.

Он не выполняет:

```text
❌ распознавание личности
❌ поиск человека по базе
❌ сравнение двух лиц
❌ регистрацию пользователя
❌ выдачу доступа
❌ управление замком
❌ управление турникетом
❌ сохранение фотографии лица
❌ сохранение биометрического шаблона
```

То есть сейчас программа работает по схеме:

```text
КАМЕРА → ЛИЦО → 68 ТОЧЕК → ЭКРАН
```

# Важное замечание

68 точек — это **facial landmarks**, то есть координаты характерных частей лица.

Они используются для геометрического описания лица, например:

```text
положение глаз
положение носа
форма рта
контур челюсти
положение бровей
```

Сами по себе эти точки не являются готовой системой распознавания личности.

Для следующего этапа СКУД отдельно потребуется модуль, который будет использовать полученные признаки для конкретной задачи системы доступа.
